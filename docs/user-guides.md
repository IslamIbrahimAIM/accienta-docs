## Guide format

Each guide follows the same shape so it is easy to follow:

1. **Goal** — what you will accomplish.
2. **Before you start** — anything you need ready.
3. **Steps** — numbered, with screenshots where helpful.
4. **Result** — how to confirm it worked.
